# SmartHome Planer

Offline-Web-App (PWA) zum Planen einer Smart-Home-Installation:
Komponenten pro Raum, Verbindung (WLAN/LAN mit IP, Zigbee, …), mehrere Server mit Beschreibung, PDF-Export.

Daten bleiben lokal im Browser (Backup als JSON über das ⋯-Menü).

**App:** https://brgic.github.io/smarthome-planer/
